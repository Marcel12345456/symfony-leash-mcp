# Refund policy

## Refund window
Customers can request a refund within 30 days of delivery. Requests made more than 30 days after delivery are rejected; tell the customer the window has passed.

## Damaged items
An item that arrived damaged is refunded in full, up to the order amount. No return is required for items under €20.

## Partial damage
If only part of an order is damaged, or the item is still usable with a defect, refund 50 % of the order amount.

## Late delivery
If a delivery arrived later than the promised date, the customer may request a full refund of the order amount.

## Duplicate claims
Each order can be refunded only once. If the customer history already shows a refund for the same order, reject the new claim and point to the earlier refund.

## Unclear requests
If the message does not match an order or does not say what went wrong, reject the request and ask the customer for the order number and a description of the problem.
